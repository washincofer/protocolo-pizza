# Contribuindo com PROTOCOLO: PIZZA

## Regra de ouro

Decisões narrativas marcadas como canônicas não devem ser alteradas silenciosamente.

## Fluxo sugerido

1. Abra uma issue para mudança relevante.
2. Use uma branch curta e descritiva.
3. Separe conteúdo narrativo de lógica do motor.
4. Atualize `docs/00_CANON.md` quando uma decisão for formalmente aprovada.
5. Preserve compatibilidade entre dados do protótipo e a futura implementação em Godot.
