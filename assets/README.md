# Assets

Organização sugerida:

- `concept/` — concept art e mapas visuais usados na pré-produção.
- `backgrounds/` — cenários finais/recortados.
- `characters/` — personagens e sprites.
- `ui/` — interface, cursores, inventário e ícones.
- `audio/` — música, efeitos e vozes.

Concept arts existentes são referência visual e não necessariamente assets finais para distribuição.
