# Projeto Godot

Estrutura inicial para a implementação final de **PROTOCOLO: PIZZA**.

O objetivo é manter narrativa e dados o mais independentes possível do motor.

## Direção

- Godot 4.x
- cenas pequenas e composáveis
- GameState central
- inventário e conhecimentos separados
- pizza como estado persistente
- conquistas orientadas por flags

O protótipo HTML continua sendo a superfície de validação enquanto os sistemas principais são desenhados.
