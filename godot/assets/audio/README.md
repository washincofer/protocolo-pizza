# Áudio — PROTOCOLO: PIZZA

Coloque os arquivos de áudio do projeto nesta pasta.

## Menu

Arquivo esperado pelo `MusicManager`:

- `menu_intro.ogg`

A faixa toca em loop enquanto a tela de menu está visível e faz fade-out ao entrar no jogo.

No Web, o navegador pode exigir a primeira interação do usuário antes de liberar áudio; o `MusicManager` tenta iniciar novamente no primeiro clique/tecla.
