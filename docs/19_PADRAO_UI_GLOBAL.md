# PROTOCOLO: PIZZA — Padrão global de UI

## Decisão
O padrão visual testado e aprovado na Recepção passa a ser a base para todos os cenários do jogo.

## Padrões globais
- Balões de fala para feedbacks e falas curtas.
- HUD de escolhas A/B/C/D com a mesma calibração visual aprovada na Recepção.
- Ícones de Troféu e Menu no HUD superior.
- Cursor cartoon com estado neutro e estado clicável.
- Inventário completo acessível pelo menu ESC; o inventário antigo inferior fica oculto.
- A antiga caixa inferior de feedback textual fica oculta quando o padrão de balões está ativo.

## Inventário
A prévia gráfica dinâmica do item selecionado na área de descrição foi desativada nesta etapa para evitar o bug de duplicação em escala gigante no build Web. O item continua sendo exibido normalmente no slot, com nome, descrição e ação.

## Menu ESC
O botão `Sair do jogo` não faz mais parte da interface de Pausa. Permanecem Continuar, Inventário, Troféus, Save / Load, Opções e Voltar ao Menu.

## Calibração futura
Posições específicas de balões, músicas, NPCs, hotspots e detalhes de cada andar serão ajustadas área por área sem alterar este padrão global.
